Mental Health Support Chatbot

A Flask-based NLP chatbot designed to provide supportive responses using TF-IDF and Cosine Similarity.

Project Structure

app.py: Main backend logic (Flask).

mental_health_data.csv: The dataset containing questions and answers.

templates/index.html: The chat interface.

static/: Contains CSS styling and JavaScript logic.

How to Run

Open your terminal/command prompt.

Navigate to this folder:

cd "Mental Health Bot"


Install dependencies:

pip install -r requirements.txt


Run the application:

python app.py


Open your browser and go to: http://127.0.0.1:5000/

Note

This is a student assignment project. It uses retrieval-based NLP to ensure accurate, pre-verified responses.
